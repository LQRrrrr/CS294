To make predictions about the future, you need data about the past. Find a data source for experimenting with how well you can forecast the past.
Find and describe a set of prediction outcomes.
What are relevant features for predicting these outcomes? 
What is a reasonable way to score the validity of predictions? Derive a proper scoring rule for your application.
Set up a trial prediction task using these outcomes and scoring function.
Since you know the outcomes, find the optimal score possible given the features at hand.
Find a method that uses only the features to make predictions. It can be trained on held-out data. Describe your method, including how you built a software implementation. How does its score compare to the best score? Do you think your method is improvable? Why or why not?
